Performance

When enabled (recommended), the AI voice model loads in the background as soon as you select text on a page, so the first right-click read of a session feels fast (~1–2 seconds). Costs ~95 MB of RAM after your first selection. Turn off to keep memory use minimal (~5–10 MB) until you explicitly invoke a read — the trade-off is a one-time ~3–6 second wait on the first read of each browser session.
